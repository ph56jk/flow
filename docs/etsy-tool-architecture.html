Flow v2 / Etsy Draft Automation

Tai lieu kien truc tool Etsy

Tai lieu nay mo ta cach tool tach rieng Flow va Etsy: may chay Flow tao anh tu Trello, backend localhost giu hang doi, extension tren may Etsy polling task va luu san pham vao Draft. Mac dinh khong publish truc tiep.

1. Muc tieu he thong

Flow

Tao anh

Lay card Trello, doc SKU/title/mo ta, tao anh bang Google Flow hoac che do API key khi du phong.

Etsy

Tao Draft

Lay anh da tao, tim listing mau theo SKU/section, copy thong tin va day listing moi vao Draft.

VM

Giu dang nhap

May ao Etsy chi chay Chrome da dang nhap va extension. Backend khong can mat khau Etsy.

Safety

Khong publish

Luon tao Draft truoc de nguoi dung kiem tra san pham that vao buoi sang.

4. Luong chay Flow

sequenceDiagram
  participant User as "User"
  participant UI as "Localhost UI"
  participant API as "Backend"
  participant Trello as "Trello"
  participant Flow as "Google Flow/API mode"
  User->>UI: Click "Chay Flow"
  UI->>API: POST /api/jobs or batch
  API->>Trello: Lay card trong list da chon
  API->>API: Doc SKU, title, description, attachment
  API->>Flow: Tao anh moi
  Flow-->>API: Anh output
  API->>Trello: Attach anh output ve card
  API-->>UI: Cap nhat job status

Nguyen tac: neu card da co anh output hop le thi co the bo qua Flow va chay Etsy truc tiep; neu can test chat luong thi ep tao anh moi.

5. Luong chay Etsy Draft

sequenceDiagram
  participant UI as "Localhost UI"
  participant API as "Backend queue"
  participant Ext as "VM Chrome extension"
  participant Etsy as "Etsy Seller"
  UI->>API: Queue listing tu anh output
  Ext->>API: Poll /api/etsy/browser-copy/queue
  API-->>Ext: Task gom SKU, title, images, section
  Ext->>Etsy: Mo listing mau cung SKU/section
  Ext->>Etsy: Copy listing, xoa anh cu, giu bang mau
  Ext->>Etsy: Upload anh moi, doi title tu Trello
  Ext->>Etsy: Luu Draft
  Ext->>API: Bao done/error

Luu y: extension khong dang nhap thay nguoi dung. No chi lam viec khi Chrome tren may Etsy con session hop le.

8. Bao mat khi public GitHub

  • .env.local, token, cookie, state runtime va output data khong duoc commit.
  • Repo chi nen public code, tai lieu, test va script cai dat khong chua credential.
  • Thong tin VM, proxy, Etsy access token, Trello token phai nam trong env rieng cua may chay.
  • Draft mode la mac dinh de giam rui ro publish sai san pham.

9. Kiem thu truoc khi chay dem

  1. Mo localhost va kiem tra health/status.
  2. Click Flow cho 1 card, xac nhan anh output dung san pham.
  3. Click Etsy cho card da co output, xac nhan VM extension nhan queue.
  4. Mo Etsy Draft, kiem tra title, SKU, section, bang mau va anh moi.
  5. Chay nhieu card lien tiep, theo doi RAM VM, so tab Chrome va hang doi loi.
